# 설계 요약 (2026-11-23 밤샘 iteration)

## 공통
- 좌표: z 위, 손바닥 아랫면 z=0. x = soft(Fin Ray) 닫힘축, y = hard 닫힘축. 단위 mm.
- 공통 제약: Fin Ray 스토퍼 `x_min = w_h/2 + 4 = 18` (hard 손가락 띠 |x|<14 와 평면상 분리 → 높이 무관 무간섭).
- Soft 모드에서 열린 hard 손끝이 Fin Ray 끝보다 ≥10 mm 위, Rigid(건전지)에서 Fin Ray 끝이 바닥 위 [3,10] mm.
- Fin Ray: L 85, 밑변 28, 폭 22, 리브 4개(R2/R4/R6/R8), 좌우 2개씩 y=±13. 직렬 고무줄로 손가락당 2.5 N 제한.
- 골판지 B골 3 mm, 빨대 Ø6 / 버블티 Ø12 가정 (실측 후 `params/common.json` 수정).

## Baseline
| | B1 회전 | B2 직선 | B3 말림 |
|---|---|---|---|
| Soft | 손바닥 윗장을 접어 내린 플랩(score 힌지), 드럼 구동 | 가이드 벽 수평 슬롯 + 빨대 핀 캐리지 | 분리형 플랩 + 빨대 축(부싱), 드럼 구동 |
| Hard | 단일 피벗 + 드럼, 쐐기 패드(≈16.9°), 손톱 플랩 | 가운데 벽 30° 경사 슬롯 캐리지 (닫히면 내려감), 평행 pinch | 2마디 텐던 손가락, k2/k1≈1.47, 공중 예비 말기 필요 |
| 손바닥 | 60×80 | 120×104 | 60×80 |

## 하이브리드
- B4 = B2 soft(슬롯 캐리지, 뿌리 2 mm) + B3 텐던 hard. 손바닥 120×80, 가운데 경사 벽 없음.

## Variation
- V5 = B1 + 1-string: 상위 균형막대에서 soft 쪽 직렬 고무줄(약), hard 쪽 프리로드(강). s ≤ 45% = soft 전용.
- V5b = B3 + 1-string: 탈락 (Rigid 에서 Fin Ray ↔ 텐던 손가락 간섭).

## 모델의 한계 (실물로 확인할 것)
- Fin Ray EI 600 N·mm² 은 미보정 추정. 힘 수치는 상대 비교용.
- 물체는 강체(스펀지 포함), 바닥·슬롯 마찰 없음. B2 슬롯 마찰과 B1 드럼 접착 강도는 시뮬 밖.
- 실은 경로만 그리고 장력 전달 손실은 계산하지 않음.
