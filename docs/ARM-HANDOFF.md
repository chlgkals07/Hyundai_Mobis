# 팔(R4) + 그리퍼 결합 핸드오프

> 대상: R4 골판지 팔을 만드는 팀원. 이 문서 하나로 ① 그리퍼가 어떻게 생겼고 ② 팔에 어떻게 붙이며 ③ 크기를 어떻게 맞추고
> ④ 회전부를 실제로 어떻게 만들고 ⑤ 우리와 같은 방식으로 팔의 시뮬레이션·조립 과정을 만들 수 있게 하는 것이 목표.
> 작성: 2026-11-23 · 그리퍼 기준안 **B5N** · 숫자는 전부 `params/` + `calc/`(SymPy) 에서 나온 값 (출처 표기).

---

## 0. 요약 (먼저 읽기)

1. **그리퍼 B5N**: 손바닥 60×88 mm. soft = 좌우 플랩에 Fin Ray 2개씩 (x 방향으로 닫힘), hard = 앞뒤 평행 링크 손가락 2개 (y 방향으로 닫힘). 실 2계통(실 A = soft, 텐던 루프 = hard)을 손바닥 위로 뽑아 당김. 무게 약 60 g (추정).
2. **붙이는 곳**: 손바닥 윗면 **가운데 26×35 mm** 만 비어 있음 → 여기에 높이 20 mm **장착 기둥**을 세우고 그 위에 손목. 실은 기둥 옆(텐던 y=±21.5, 실 A x=±17)으로 올라옴.
3. **wrist roll 필수**: 그리퍼가 고정된 두 축(x, y)으로만 닫히므로 물체(건전지·케이블) 방향을 손목 회전으로 맞춰야 함.
4. **열림이 팔에 걸리는 문제 → "덜 열기"가 정답**: soft 를 90° 펼치면 반폭 131 mm, 손바닥 위로 28 mm 솟아 손목·기둥에 걸릴 수 있음 (가정 치수 시뮬: 손목 수평거리 130 mm 이하에서 팔 기둥과 간섭).
   주방 스펀지(110 mm)도 **20°** 면 충분 → **soft 열림 스토퍼를 30–45° 로** 바꾸면 반폭 80–101 mm, 손바닥 위로 거의 안 솟음. 팔을 키우는 것보다 싸고 확실.
5. **실이 팔을 지나갈 때**: 빨대 피복(보우덴)으로 감싸 팔 움직임과 실 길이를 분리. 단 꺾임 마찰로 손 쪽 장력이 커짐 (180° 꺾이면 1.9–2.6 배 → hard 27.5 N 이 52–71 N). **꺾임 총합을 180° 이하로**.
6. **회전부 공통 레시피** (§4): 빨대 = 핀만, 토크는 골판지 면 접착으로, 구멍 지름은 시험편으로 결정, 축 방향 빠짐은 종이 와셔.
7. **재현**: `params/arm/R4.json` 을 실측값으로 바꾸고 `npm run build` → `docs/site/arm.html` 에서 팔+그리퍼 간섭을 바로 봄. 팔 조립 애니메이션은 `src/viewer/assembly.ts` 의 블록 정의에 "팔" 블록을 추가하는 방식 (§6).

## 2. 결합 인터페이스

### 2-1. 손바닥 윗면 배치 (위에서 본 그림, 단위 mm, 원점 = 손바닥 중심)
```
            y=+44 ┌────────────────────────────┐
                  │  ◎ soft 드럼(x=±17~30, y=33) │← 실 A 가 x=±17 에서 위로
            y=+21.5 ·········· ● 텐던 구멍 (x=0)
                  │      ┌──────────┐          │
                  │      │ 장착 기둥 │ ← 비어 있는 영역 x ±13, y ±17.5
                  │      │ 24 × 30  │          │   (calc/out/envelope.json mount_free_rect)
                  │      └──────────┘          │
            y=-21.5 ·········· ● 텐던 구멍
                  │ ○ 복원 고무줄 고정점 (x=±16, y=-13)
            y=-44 └────────────────────────────┘
                 x=-30                       x=+30   (플랩은 x=±30 모서리에서 접힘)
```
- **장착 기둥**: 골판지 적층 블록 24×30, 높이 20 mm (`params/arm/R4.json` mount). 손바닥 윗장에 풀칠 + 삼각 보강 4개.
  기둥 높이 20 은 soft 드럼(손바닥 위 최대 +19)과 실 A 가 손목 아래로 지나갈 공간.
- 손목 블록은 기둥 위. **wrist roll 축 = 기둥 중심 수직축**. 올라오는 실(실 A 는 균형막대 뒤 1가닥, 텐던 루프는 2가닥)은 roll 축 근처를 지나가야 roll 시 꼬임이 작음 → 기둥 옆면에 빨대 피복을 세워 붙여 위로.
- 그리퍼 local 좌표: 손바닥 아랫면 z=0, 윗면 z=6, x = soft 닫힘 축, y = hard 닫힘 축. `src/core/arm.ts` 의 `armFK` 가 기둥 → 손목 → 팔로 변환.

### 2-2. 팔이 만족해야 할 것
| 요구 | 값 / 이유 |
|---|---|
| 손목 높이 범위 | 손바닥 높이 101 mm(Rigid) ~ 약 140 mm(접근) + 손바닥 6 + 기둥 20 + 손목 블록 → 손목(전완 끝)이 바닥 위 약 160–200 mm 를 오가야 함 |
| 그리퍼 자세 | **손바닥 수평(그리퍼 수직)** 유지 — 위에서 내려 잡는 방식. 손목 pitch 를 평행 링크/실로 수평 유지하거나, 손목 pitch 관절을 따로 둠 (`wristPitch: "level"`) |
| wrist roll | ±90° 이상 (물체 방향 정렬). 0°/90° 두 자세만이라도 있으면 됨 |
| 하중 | 그리퍼 약 60 g + 물체 (건전지 23 g) + 실 장력의 반력. 실 장력은 그리퍼 내부에서 닫히는 힘이지만, 보우덴 피복이 팔에 고정되면 피복 압축력(최대 수십 N)이 팔에 걸림 (§3) |
| 그리퍼와의 간섭 | `npx tsx scripts/arm-check.ts` → `docs/arm-check.md` 표가 전부 ✓ 이어야 함 |

## 3. 크기 맞추기 — 열림이 팔에 걸리는 문제

### 3-1. soft 열림 각 vs 그리퍼 크기 (SymPy, `calc/envelope.py`)
| soft 열림 제한 | x 반폭 | 손바닥 위로 솟음 | 실 A 당김 |
|---|---|---|---|
| 90° (현재 전개도) | 131.0 mm | **+28.0 mm** | 22.2 mm |
| 60° | 117.5 | +16.2 | 15.4 |
| **45°** | 101.4 | +8.5 | 12.0 |
| **30°** | 80.5 | +0.1 | 8.6 |
| 20° | 64.5 | −5.5 | 6.3 |

물체를 감싸는 데 필요한 열림: 감자칩 2.8°, 스펀지(70) 8.5°, **주방 스펀지(110) 20.3°** → 90° 는 과함.

### 3-2. 가정 치수 팔에서 확인한 것 (`docs/arm-check.md`)
- 손목 수평거리 r ≤ 130 mm (가깝게 잡을 때) + soft 90°: **펼친 Fin Ray 가 팔 기둥(column)과 간섭**. 45° 이하이면 해소.
- roll 90° 로 돌리면 Fin Ray 가 기둥 방향을 피해 90° 도 통과.

### 3-3. 선택지
| 방법 | 장점 | 단점 | 추천 |
|---|---|---|---|
| **A. soft 열림 스토퍼 30–45°** | 그리퍼 쪽 작은 블록 1개, 실 당김도 줄어듦 | "완전 개방" 포기 (필요 없음 — 3-1) | ✅ **기본** |
| B. 팔을 키움 (기둥 낮게/상완 길게, 손목 오프셋) | 그리퍼 그대로 | 팔 무게·처짐 증가, 실 경로 길어짐 → 마찰↑ | 실측 후 A 로 부족할 때만 |
| C. 가까이 잡을 땐 roll 90° | 부품 추가 없음 | 물체 방향 정렬과 충돌할 수 있음 | 보조 |

**A 의 구현**: soft 플랩 바깥면과 손바닥 윗면 사이에 "열림 스토퍼"(삼각 블록) — 플랩이 45° 에서 닿게. 각도별 블록 높이는 `calc/envelope.py` 에 한 줄 추가해 계산할 것 (아직 전개도에 없음 → TODO §7).

### 3-4. 실 경로 (텐던 커플링)
- 실을 그냥 팔 관절 위로 걸면 팔이 움직일 때 실 길이가 바뀌어 **그리퍼가 저절로 쥐거나 풀림**.
- 해결: **보우덴** — 실을 빨대 피복 안에 넣고, 피복 양 끝을 ① 장착 기둥 위 ② 조작부(손잡이 판/모터)에 고정. 팔이 움직여도 피복 길이가 일정하면 실 길이도 일정.
- 대가 = 마찰 (capstan, 장력비 e^{μθ}, μ 0.2–0.3 가정):

| 피복 꺾임 총합 | μ=0.2 | μ=0.3 | hard 27.5 N 이 손 쪽에서 |
|---|---|---|---|
| 90° | 1.37 | 1.60 | 38–44 N |
| 180° | 1.87 | 2.57 | 51–71 N |
| 360° | 3.51 | 6.59 | 97–181 N ✗ |

→ 피복은 **관절 축을 지나가게(축 위로 크게 돌지 않게)**, 꺾임 총합 180° 이하. 실은 낚싯줄/연줄처럼 매끄러운 것, 빨대 속에 비누·연필심(흑연) 칠.
- 대안: 관절마다 골판지 풀리(드럼)를 축과 같은 중심에 두고 실을 감아 넘기면 관절 각과 무관하게 길이 일정 (§4 드럼 레시피 그대로).

## 4. 원형 회전부 만드는 법 (그리퍼·팔 공통 레시피)

그리퍼에서 확정한 방식. 팔 관절(어깨·팔꿈치·손목 roll)도 같은 방식으로 만들면 시뮬·전개도 도구를 그대로 씀.

### 4-1. 구멍과 핀 (모든 회전 관절)
1. **구멍 맞춤 시험편 먼저** (`patterns/B5N` 1번 장): 일반 빨대(Ø6) 용 구멍 Ø6.0 / 6.3 / 6.6 / 7.0, 2겹·3겹 각각.
   빨대가 **덜컥거리지 않고 손가락으로 부드럽게 도는** 구멍을 골라 `params/common.json` 반영 → 전체 전개도 재생성.
2. 빨대는 **판 구멍에서 직접 회전** (버블티 빨대 부싱은 Ø6 빨대에 3 mm 씩 헐거워 평행 링크에 부적합).
3. 구멍 테두리 보강: 구멍 뚫기 전 그 자리에 투명 테이프 2겹 → 송곳 → 연필로 넓힘. 또는 풀 먹인 종이 와셔(원 Ø14, 구멍 Ø6.3) 를 양면에.
4. **축 방향 빠짐 방지**: 빨대 양끝 바깥에 종이 와셔를 끼우고 테이프 한 바퀴 (와셔와 판 사이 0.5 mm 유격).
5. 빨대 속에 골판지 라이너 종이를 말아 넣어 찌그러짐 방지.
6. 정렬: 두 장(브래킷 2장, 링크 막대 2장)은 **겹쳐서 한 번에 뚫고**, 붙일 때 빨대를 미리 끼운 채로 풀칠 → 구멍이 자동 정렬.

### 4-2. 드럼(원판) — 실을 감아 회전으로 바꾸는 부품
1. 원판 3장 (큰 r – 작은 r−3 – 큰 r). 중심 십자에 송곳 구멍 먼저.
2. 원 자르기: 커터칼로 짧은 직선 여러 번 → 16각형 → 칼끝으로 모서리 다듬기 (지름 26–32 mm 는 충분). 원형 커팅 지그 불필요.
3. 빨대를 지그로 3장 중심 맞춰 풀칠 → 가운데에 깊이 3 mm 실 홈.
4. 홈 바닥에 테이프 1바퀴 (골판지 단면이 실을 갉아먹지 않게).
5. 큰판 1장 가장자리(3 mm 안)에 송곳 구멍 → 실 매듭 + 테이프. 홈에 1바퀴 이상 감기 (감는 방향 = 실을 당길 때 원하는 쪽으로 도는 방향, 조립 후 손으로 확인).
6. **토크 전달은 골판지 면 접착으로**: 드럼을 빨대에 풀칠하면 플라스틱이라 헛돎. hard 는 드럼(9 mm)을 바깥 링크 막대 2장 사이에 끼워 면 풀칠 (`docs/diagrams/hub.svg`). 팔 관절 풀리도 링크 판 사이에 끼울 것.
7. 접는 힌지(score)에 붙는 soft 드럼은 플랩 바깥면에 세워 붙이고 삼각 보강 2개 (선 접촉이라 약함).

### 4-3. 실 고정·장력 조정
- 매듭 전에 테이프로 임시 고정 → 전 범위(완전 열림 ↔ 완전 닫힘) 동작 확인 → 매듭.
- 균형막대(whiffletree): 좌우 실을 양 끝에, 가운데에서 1가닥. 먼저 닿은 쪽이 멈추고 반대쪽이 계속 닫힘.
- 직렬 고무줄(실 A): 손잡이 바로 아래 1토막 + 옆에 눈금 → 늘어난 길이 = 힘.

## 5. 레포 구조와 실행

`README.md` 참고. 팔 작업에 쓰는 파일만 추리면:

| 파일 | 역할 | 팀원이 할 일 |
|---|---|---|
| `params/arm/R4.json` | 팔 치수 (현재 **가정값**) | R4 실측값으로 교체, `_status` 를 `"measured"` 로 |
| `src/core/arm.ts` | 팔 정기구학 `armFK`, 2링크 역기구학 `armIK`, 그리퍼 장착 `transformAssembly`, 충돌용 `combinedDesign` | 관절 구성이 다르면 여기 수정 (예: wrist pitch 가 실 구동이면 각도 입력) |
| `scripts/arm-check.ts` | 대표 자세 × soft 열림 제한별 팔↔그리퍼 간섭표 → `docs/arm-check.md` | 실측 치수로 재실행, 전부 ✓ 될 때까지 R4.json·soft 제한 조정 |
| `src/viewer/arm.ts` + `arm.html` | 팔 결합 시뮬 페이지 → `docs/site/arm.html` | 슬라이더로 확인. 관절 추가 시 슬라이더 추가 |
| `calc/envelope.py` | 그리퍼 점유 공간·장착 영역·마찰 (SymPy) | 팔 쪽 계산(관절 토크, 처짐, 실 경로 꺾임)을 `calc/arm.py` 로 새로 |

```bash
npm ci && pip install sympy          # 최초 1회 (Playwright Chromium 이 있어야 스크린샷·영상)
python3 calc/run_all.py && python3 calc/envelope.py
npx tsx scripts/arm-check.ts          # 팔↔그리퍼 간섭표
npm run build                         # docs/site/{bench,assembly,arm}.html 갱신 — 브라우저로 바로 열기
```

## 6. 우리와 같은 방식으로 팔 시뮬·조립 과정 만들기

그리퍼는 아래 순서로 만들었고, 팔도 같은 틀에 끼우면 됨.

| 단계 | 그리퍼에서 한 것 | 팔에서 할 것 |
|---|---|---|
| ① 치수 단일 소스 | `params/B5N.json` | `params/arm/R4.json` (실측) |
