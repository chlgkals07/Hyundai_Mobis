# B6P 최종 검토 (2026-11-28)

영상 과제용 간이 그리퍼 B6P(접는 평행사변형 hard + Fin Ray soft, 교차 실)의 제출 준비 상태 점검.
수치는 `calc/out/B6P.json`(SymPy, 22개 조건 전부 통과)과 헤드리스 시뮬(`scripts/test.ts`, `scripts/approach.ts`) 결과.

## 1. 결론

**간이 그리퍼 제출물로 충분하다.** 컨셉(앞뒤 hard 집기 + 좌우 Fin Ray 감싸기)이 그대로 보이고, 영상 물체 5종을 시뮬에서 모두 쥔다.
제작은 판 26조각·빨대 핀 0개·매듭 4개로 하루 안에 끝낼 수 있다.
남은 위험은 **실물로만 확인할 수 있는 3가지**(Fin Ray 휘는 정도, 접는 관절 수명, 팔을 거친 실 마찰)라서, 전체 제작 전에 **손가락 1개 + Fin Ray 1개**를 먼저 만들어 확인한다.

## 2. 기능 검증

| 항목 | 결과 | 근거 |
|---|---|---|
| 물체 5종 (건전지·뚜껑·케이블·감자칩·스펀지) | **5/5** | 시뮬 프리셋 |
| 부품·바닥·물체·실 간섭 | **0건** | 6자세, OBB + 실 걸림 검사 |
| 손끝 평행 (손끝판 수직) | 유지 | 평행사변형 (두 링크 75 mm 동일) |
| 수직 순응 (팔 높이 오차) | **12 mm** 까지 건전지·케이블 유지 | 손톱 접힘, approach 테스트 |
| hard 개구 / soft 열림 | 135 mm / 30° | F1, S2 |
| 집는 힘 (영상용) | pinch 1.5 N ≥ 건전지 최소 0.85 N | E10 |
| 실 장력 (손가락 하나) | hard 6.1 N, soft 6.5 N | F4, S8 |
| 손잡이 힘 (두 가닥 + 구멍 빨대, 팔 마찰 제외) | hard 13 N, soft 17 N | 캡스턴 계산 |
| 당기는 거리 | hard 15 mm, soft 14 mm | 실 늘어남에 여유 |
| 건전지 집을 때 손바닥 높이 | 115.4 mm | 팔 담당에 전달 필요 |

## 3. 조립 난이도 점검 (순서대로 따라가 보며)

| 단계 | 난이도 | 확인한 것 / 주의 |
|---|---|---|
| 인쇄·자르기 (전량판 4장, 26조각) | 쉬움 | 전부 직선·사각. 원판·V자 없음 |
| 손바닥 2장 + 구멍 | 쉬움 | 실 구멍 4개 Ø6.5(슬리브), 매듭·고무줄 구멍 Ø3. 정밀 위치 불필요 |
| 빨대 슬리브 4개 | 쉬움 | **윗면 평평하게**(팔 장착부가 덮음), 아래로 4 mm |
| Fin Ray 4개 | **중간** | 병으로 눌러 펴기 → 삼각형 접기 → 리브 16개 테이프. R8(4 mm)은 생략 가능 |
| Fin Ray → 날개 | 쉬움 | 앞 탭 26 mm 면 접착. **날개를 접기 전, 평평할 때** 붙이기 |
| 닫힘 스토퍼 블록 | 쉬움 | ⚠ **이번 검토에서 수정**: Fin Ray 탭 두께만큼 블록을 2 mm 안쪽(x=±26.3)으로 (S10) |
| 접는 상자 2개 | 쉬움–중간 | 띠 1장에 접는 선 4개 + 테이프. **탭부터 붙여 상자 → 그다음 손바닥에**. 두 링크 길이 동일 확인 |
| 손끝판(ㄱ자)·손톱 | 중간 | 손톱 3장 중 1장만 탭 남기기. ㄱ자 접착 면이 12×24로 작아 삼각 보강 필수 |
| 교차 실·고무줄 | 쉬움–중간 | 매듭 4개. 실 경로는 설명서 그림대로. 교차 실끼리 안 닿는지 확인 |

예상 시간: 1인 약 4시간, 2인 약 2.3시간 (자르기·Fin Ray 분담).

## 4. 남은 위험과 대응

| 위험 | 왜 계산으로 못 잡나 | 대응 |
|---|---|---|
| Fin Ray 휘는 정도 | 눌러 편 골판지의 굽힘 강성(EI)을 아직 안 쟀음 | Fin Ray 1개 먼저 만들어 손가락으로 눌러 확인. 너무 뻣뻣하면 한 번 더 눌러 펴기 |
| 접는 관절 수명 (양방향) | 골판지 접힘 피로는 모델 밖 | 깊게 누르고 여러 번 길들인 뒤 바깥 면 테이프. 찢어지면 테이프 힌지(1 mm 띄워 양면)로 교체 |
| 팔을 거친 실 마찰 | 팔 실 경로(꺾임 수) 미정 | 매끄러운 실, 가이드 일렬. 그래도 무거우면 조작판에 2:1 도르래 |
| 손톱 테이프 힌지 | 반복 접힘 | 여분 손톱을 미리 잘라 두기 |
| 손바닥 높이 115 mm | 이전 101 mm에서 +14 | 팔 담당에게 전달 (내림각 하한 재계산) |

## 5. 이번 검토에서 고친 것

- **닫힘 스토퍼 블록 위치**: 블록 아래 모서리가 닿는 날개 위치(힌지에서 14 mm)가 Fin Ray 앞 탭(4…30 mm) 위라, 탭 두께만큼 날개가 일찍 멈춤 → 블록 바깥 면 28.0 → **26.3 mm** (SymPy S10, 시뮬은 손바닥–날개 인접 처리라 못 잡음)
- **빨대 슬리브**: 윗면 평평 (팔 장착부 24×30 과 겹침 방지)
- 설명서: Fin Ray 탭은 날개 접기 전에 붙이기
