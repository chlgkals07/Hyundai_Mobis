- **검증** (×2): SymPy 전 조건 통과 3점 + 6자세 간섭 0건 2점 (건당 −0.5)
- **제작 용이** (×2): 자를 판 개수(수량 합) 최소 5점 → 최대 2점 선형
- **손 구동** (×1): 최대 실 장력 20 N 이하 5점 → 70 N 0점 선형
- **제작 리스크** (×2): 정성 (근거는 세부 지표 표)
- **핸드형 가산점** (×1): 정성 — 영상 가산점(핸드형 구조) 설명력
