> 상태: **기록만 함, 아직 코드·전개도에 반영하지 않음.** (2026-11-23, PR #1 머지 직후)

## 0. 기준 구성
- 그리퍼 **B5N** (평행 링크 hard + 긴 손톱, Fin Ray soft) + 팔 **R4** (`arm/R4-B5N/`, 평행사변형 링크 → 그리퍼 항상 수직)
- 머지 커밋: `f02fef1` (PR #1)

## 1. 힘 목표 — 영상 과제 전용으로 낮춤 (가장 중요)
현재 B5N 목표(pinch 8 N, Fin Ray 손가락당 2.5 N)를 실 5계통·꺾임 270–450° 를 거쳐 손으로 당기면 비현실적:

| 조건 | 손에 걸리는 힘 |
|---|---|
| hard pinch 8 N | 141–580 N ✗ |
| soft 한계 2.5 N/손가락 (드럼 r13) | 273 N ✗ |

영상 물체를 드는 데 필요한 pinch (안전계수 3, μ 0.4, 두 면): 건전지 0.85 N · 케이블 0.74 N · 스펀지 0.44 N · 뚜껑 0.11 N.

**수정:** 영상용 힘 프로파일 추가
- hard pinch 목표 **1.5 N** (건전지 대비 약 1.8 배 여유)
- soft 손가락당 힘 한계 **0.5 N** (감자칩 파손 ~5 N 대비 충분, 감싸기용)
- 직렬 고무줄(힘 눈금)도 이 값에 맞춰 재선정
- 예상 손 힘: hard pinch 1 N 기준 18–72 N → 1.5 N 이면 이보다 약간 큼 → **꺾임 줄이기(§4)와 같이** 해야 30 N 안팎

## 2. soft 드럼 → r 26 부채꼴(섹터)
- soft 열림을 30° 로 제한하면 드럼 실제 회전은 38° (30° → −8°) 뿐 → 원판 대신 반지름 26 mm 부채꼴이면 장력 절반 (soft 0.3 N 기준 손 힘 33 → 16 N)
- 확인할 것 (SymPy + 충돌): 부채꼴이 장착 기둥(x ±12, y ±15)·텐던 구멍(y ±21.5)·손목 링(반경 25)과 안 겹치는지. drum_y = 33 위치라 겹치지 않을 것으로 보이나 계산으로 확정
- B5N 단독 버전(`params/B5N.json`)에도 같이 반영

## 3. soft 열림 스토퍼 30° (그리퍼 쪽 부품으로)
- PR 은 "임시 스토퍼"로만 언급. 30° 는 필요조건으로 확인됨: 손목 0° 에서 Fin Ray ↔ 끝판 여유 30° 15 mm, **45° 부터 간섭**
- 그리퍼 전개도에 열림 스토퍼 블록 추가, `params/B5N.json` soft.phi_open_deg 90 → 30, `calc/envelope.py` 에 블록 높이 계산

## 4. 실 경로 꺾임 줄이기
- 각 계통(받침·올림·손목·A·B) 꺾임 총합을 `calc/arm.py` 에서 계산 → 목표 계통당 ≤ 270°
- 매끄러운 실(낚싯줄/연줄), 빨대 가이드 끝 다듬기, 흑연·비누
- 이동 풀리·균형막대는 두 가닥을 당기므로 손 힘 2 배임을 문서에 명시 (대신 좌우 균형)

## 5. 팔 내림 하한 19° → 21–22°
| 목표 손바닥 높이 | 필요한 내림각 |
|---|---|
| 건전지 Rigid 101.4 mm | 19.0° (현재 하한과 같아 여유 0) |
| 감자칩 Soft (Fin Ray 끝 바닥+2) 96.9 mm | 20.5° |
| 긴 손톱 순응 한계 89.4 mm | 23.1° |

→ 하한 매듭을 21–22° 로. 내림 중 반지름 방향 이동 9.8 mm 는 soft 축 방향이라 허용.

## 6. 규정: 젓가락 축 → 종이 축
- 허용 재료(골판지·고무줄·실·빨대·테이프 "등")에 젓가락 없음 → 감점 위험
- 겉종이를 단단히 말아 빨대 속에 넣은 종이 축을 기본으로, 제작 시트·재단도 문구 수정. 풀은 허용(하민 확인)

## 7. 레포 통합 (규칙 정리)
- 팔 치수를 `arm/R4-B5N/viewer.ts` 하드코딩 → `params/arm/R4.json` (현재 가정값 덮어쓰기) 로 옮기고 viewer 가 읽게
- 복사된 그리퍼 상수(7.9676, 30, palmZ 20)를 `calc/out/B5N.json`·params 에서 읽게
- `calc/arm.py`: 도달 높이, 내림각, 꺾임 총합, 손 힘, 관절 토크 (SymPy)
- 우리 충돌 엔진(`src/core/arm.ts` · `scripts/arm-check.ts`)으로 R4 실제 형상 + B5N 간섭 검사 (손목 0/45/90°, 내림 0–22°, 받침 0–45°)
- `package.json` 에 `esbuild` 명시 (현재 vite 에 딸려 우연히 설치됨)
- 재단도: 팔 A3(reportlab) / 그리퍼 A4 — 둘 다 유지하되 A3 인쇄 가능 여부 확인, 안 되면 A3 를 A4 2장 타일로

## 8. 운영
- 손잡이 약 8 개 → 촬영 시 조작자 2명, 손잡이 색 라벨
- 작업 범위: 받침 0–45° × 반지름 약 300 mm 원호 → 물체를 원호 위에 배치

## 9. 최종 패키지에 넣을 것 (반영 후)

- 재단도: 그리퍼 A4 + 팔 A3, 구멍 맞춤 시험편 먼저
