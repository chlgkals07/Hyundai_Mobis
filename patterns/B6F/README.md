## 부자재 (자르지 않음)

- 빨대 자르기 (빨대 2개면 충분): Fin Ray 리브 R2 약 20 · R4 약 15 · R6 약 9 · R8 약 4 mm(생략 가능) × 4개 손가락 — 도면 길이 22.4/16.8/11.2/5.6 에서 벽 두께만큼 짧게, 접은 삼각형에 대 보고 다듬기. 양끝 테이프 힌지
- soft 실 (좌우 한 가닥 루프): 오른쪽 플랩 매듭 구멍 → 손바닥 구멍 x=+5 위로 → 손잡이 → x=−5 아래로 → 왼쪽 플랩 매듭. 균형막대 불필요 (한 가닥이 양쪽을 같이 당김)
- soft 복원 고무줄 2: 손바닥 윗장 고무줄 구멍 ↔ 플랩 바깥면. soft 열림 제한 실: 플랩 ↔ 손바닥, 열림 30° 에서 팽팽하게
- 영상용 힘: Fin Ray 손가락당 0.5 N → soft 실 9.5 N, hard pinch 1.5 N → hard 실 8.3 N (손가락 하나 기준). 손잡이는 두 가닥을 당기므로 손잡이 힘 ≈ 2배. 복원 고무줄은 확실히 약하게
- 빨대 터널: 손가락당 4개 × 12 mm (근위 2, 원위 2), 판 안쪽 면 가운데에 테이프 → 실 모멘트 팔 약 9 mm (판 6 + 빨대 반지름 3)
- hard 실 (손가락마다 1가닥, 또는 앞·뒤를 손잡이에서 묶음): 원위 '매듭' 구멍 → 원위 터널 2 → 근위 터널 2 → 손바닥 구멍 y=±34 위로 → 손잡이
- 복원 고무줄: J1(손바닥 윗면 ↔ 근위 바깥면) 1, J2(근위 바깥면 ↔ 원위 바깥면) 1 — J2 쪽을 J1 의 약 2.2 배 세게 (고무줄 2겹 등). 휴지 자세: 근위 40° 벌어짐, 원위 곧게
- 조작 순서: 공중에서 실을 60% 당겨 원위를 먼저 말고 → 내림 → 끝까지 조임 (바닥에 손톱이 먼저 닿은 채 말면 걸림, B3 시뮬에서 발견)

## 조립 순서

1. 손바닥: 윗장(플랩 포함) + 아랫장 풀칠(플랩 풀칠 금지), 구멍(soft 2, hard 2, 매듭 2, 고무줄 2) 함께 뚫기, 닫힘 스토퍼 블록.
2. Fin Ray 4개 → 플랩 안쪽 면 표시에 앞 탭 풀칠.
3. 손가락 2개: 근위·원위 판 각 2장 적층 → 1 mm 띄워 놓고 바깥 면 테이프 힌지(J2) → 근위 위 끝을 손바닥 아랫장 가장자리에 테이프 힌지(J1). 안쪽 면에 빨대 터널 4개.
4. 실: 원위 매듭 → 터널 4개 → 손바닥 구멍 → 위. 복원 고무줄 J1·J2 (J2 를 더 세게) → 휴지 자세(근위 40° 벌어짐) 확인.
5. 동작: 공중에서 60% 당겨 원위를 말고 → 내림 → 조임. soft 실로 Fin Ray 감싸기.
