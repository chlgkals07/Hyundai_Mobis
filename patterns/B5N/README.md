## 부자재 (자르지 않음)

- 긴 손톱 14 mm (3겹): 접히면 최대 11.6 mm 순응. 접히기 전엔 손톱 안쪽 면이 쥐는 면
- 일반 빨대(Ø6) Fin Ray 리브: 손가락당 22.4 / 16.8 / 11.2 / 5.6 mm × 4개 손가락 (+ 테이프 힌지 양끝)
- 빨대 핀/축: 손가락당 4개 × 32 mm (안쪽 축·바깥 축·E_in·E_out). 구멍은 시험편으로 고른 지름. 속에 라이너 종이를 말아 넣어 보강
- 실 A (soft): soft 드럼 홈에 매듭 → 1/2바퀴 → 드럼 안쪽 접선(x=±17)에서 위로 → 균형막대 양끝 → 가운데 → 직렬 고무줄 → 손잡이
- 실 B (텐던 루프 1가닥): 앞 드럼 매듭 구멍 → 홈 1바퀴 → 안쪽 접선 → 손바닥 구멍 y=+21.5 → 손잡이/모터 풀리 → 구멍 y=−21.5 → 뒤 드럼 1바퀴 → 매듭. 감는 방향: 위로 당길 때 손가락이 닫히는 쪽
- 복원 고무줄: soft 플랩 2 (플랩 바깥면 ↔ 손바닥 윗면 구멍), hard 2 (바깥 링크 끝 ↔ 브래킷 바깥 위)
- 텐던 장력 27.5 N (pinch 8 N), 당김 17.1 mm / 손가락 개구 103 mm

## 조립 순서

1. 구멍 맞춤 시험편 → 빨대 구멍 지름 결정.
2. 손바닥: 윗장(플랩 포함) + 아랫장(좌우 1.5 mm 좁게) 엇갈려 풀칠, 플랩 부분 풀칠 금지. 닫힘 스토퍼 블록 부착.
3. Fin Ray 4개 → 플랩 끝에 밑판으로 고정. soft 드럼(3장) → 플랩 바깥 힌지선에 세워 붙이고 삼각 보강.
4. 브래킷 4장: 탭 접어 손바닥 아랫면에 평행하게 (빨대를 미리 끼운 채 풀칠하면 정렬), 삼각 보강, 스토퍼 탭.
5. 링크: 바깥 막대 2개 사이에 드럼을 끼워 면 접착(빨대가 아니라 골판지로 토크 전달). 안쪽 막대 2개는 드럼 양옆. 축 빨대 끼우기.
6. 커플러 측판 2장 + 손끝판 3겹 + 핀 2개 → 손으로 돌려 손끝판이 계속 수직인지 확인.
7. 긴 손톱(3겹) 테이프 힌지 + 손톱 스토퍼 + 고무줄. 실 A·텐던 루프·복원 고무줄 연결 후 전 범위 동작 확인.
