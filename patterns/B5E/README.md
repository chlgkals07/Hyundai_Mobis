## 부자재 (자르지 않음)

- 긴 손톱 14 mm (3겹): 접히면 최대 11.6 mm 순응. 접히기 전엔 손톱 안쪽 면이 쥐는 면
- 일반 빨대(Ø6) Fin Ray 리브: 손가락당 22.4 / 16.8 / 11.2 / 5.6 mm × 4개 손가락 (+ 테이프 힌지 양끝)
- 빨대 핀/축: 손가락당 4개 × 32 mm (안쪽 축·바깥 축·E_in·E_out). 구멍은 시험편으로 고른 지름. 속에 라이너 종이를 말아 넣어 보강
- 실 A (soft): soft 레버 끝 매듭 구멍에 묶음 → 위로(x≈±29) → 균형막대 양끝 → 가운데 → 직렬 고무줄 → 손잡이. 감기 없음
- 실 B (텐던 루프 1가닥): 앞 hard 레버 끝 매듭 → 손바닥 구멍 y=+28.5 → 손잡이 → 구멍 y=−28.5 → 뒤 레버 끝 매듭. 감기 없음
- 영상용 힘: pinch 1.5 N → 텐던 6 N, Fin Ray 손가락당 0.5 N → 실 A 5.2 N. 복원 고무줄은 이보다 확실히 약하게
- 복원 고무줄: soft 플랩 2 (플랩 바깥면 ↔ 손바닥 윗면 구멍), hard 2 (바깥 링크 끝 ↔ 브래킷 바깥 위)
- 텐던 장력 6 N (pinch 1.5 N), 당김 16.3 mm / 손가락 개구 103 mm

## 조립 순서

1. 구멍 맞춤 시험편 → 빨대 구멍 지름 결정.
2. 손바닥: 윗장(플랩 포함) + 아랫장(좌우 1.5 mm 좁게) 엇갈려 풀칠, 플랩 부분 풀칠 금지. 닫힘 스토퍼 블록 부착.
3. Fin Ray 4개 → 플랩 끝에 밑판으로 고정. soft 레버(2겹) → 꼭짓점을 힌지선에 맞추고 발을 플랩 바깥면에 세워 풀칠 + 삼각 보강. 팔이 손바닥 슬롯을 지나 윗면 위로 가는지 확인. 레버 팔이 손바닥 윗면(슬롯 끝)에 닿는 φ ≈ 35.1° 가 자연 열림 스토퍼 (SymPy E11) — 별도 30° 스토퍼 블록 불필요.
4. 브래킷 4장: 탭 접어 손바닥 아랫면에 평행하게 (빨대를 미리 끼운 채 풀칠하면 정렬), 삼각 보강, 스토퍼 탭.
5. 링크: hard 레버(3겹)의 발을 바깥 막대 2개 사이에 끼워 면 접착, 꼭짓점 구멍 = 바깥 축. 안쪽 막대 2개는 레버 양옆. 축 빨대 끼우기. 레버 끝이 안쪽 축에 안 닿는지 손으로 끝까지 돌려 확인 (여유 약 1 mm).
6. 커플러 측판 2장 + 손끝판 3겹 + 핀 2개 → 손으로 돌려 손끝판이 계속 수직인지 확인.
7. 긴 손톱(3겹) 테이프 힌지 + 손톱 스토퍼 + 고무줄. 실 A·텐던 루프는 레버 끝 구멍에 매듭만. 복원 고무줄은 약하게 → 전 범위 동작 확인.
