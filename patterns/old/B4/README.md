## 부자재 (자르지 않음)

- 일반 빨대(Ø6) Fin Ray 리브: 손가락당 22.4 / 16.8 / 11.2 / 5.6 mm × 4개 손가락 (+ 테이프 힌지 양끝)
- 일반 빨대 핀: soft 70 mm × 4 / hard 축 42 mm × 2, 텐던 고리 8 mm × 8
- 굵은 빨대 부싱 7 mm × 4 (텐던 손가락 피벗, 손바닥 앞·뒤 모서리)
- 고무줄: 캐리지 복원 2, J1 2, J2 2 (k2/k1 ≈ 1.9 → J2 를 두 겹)
- 조작 순서(B3 와 같음): 공중에서 실 B 60% → 내림 → 끝까지

## 조립 순서

1. 손바닥 2장 엇갈려 풀칠, 가이드 벽 위치·실/텐던 구멍 표시.
2. Soft 가이드 벽 4장을 손바닥 아랫면에 접착, 빨대 핀 미끄럼부터 확인 (B2 와 같은 10분 테스트).
3. Fin Ray 4개 조립 → 캐리지(뿌리 2 mm 로 짧음)에 고정 → 핀으로 벽에 걸기.
4. 텐던 손가락 2개: 근위·원위 3장 적층, J2 힌지, 안쪽 고리 4개, 바깥 고무줄 (B3 와 같음).
5. 손바닥 앞·뒤 모서리 부싱에 텐던 손가락 축 끼우고, 텐던을 손바닥 구멍으로 올림.
6. 놓았을 때 캐리지 x=45, 손가락 θ1=40° 로 돌아오는지 확인.
