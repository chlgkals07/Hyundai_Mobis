## 부자재 (자르지 않음)

- 일반 빨대(Ø6) Fin Ray 리브: 손가락당 22.4 / 16.8 / 11.2 / 5.6 mm × 4개 손가락 (+ 테이프 힌지 양끝)
- 굵은 빨대(Ø12) 부싱: 7 mm × 4 (hard 피벗, 손바닥 앞·뒤 모서리 윗면)
- 일반 빨대 축: 42 mm × 2 (hard)
- 실 A: 드럼 2개 각 3바퀴 + 위로 150 mm / 실 B: 동일
- 직렬 고무줄(힘 제한): 실 A 손잡이 바로 아래 1토막, 옆에 눈금 (2.5 N/손가락에서 늘어나기 시작하도록 1차 실물로 길이 조정)
- 복원 고무줄: 플랩 2, hard 2

## 조립 순서

1. 윗장 플랩 점선을 자 대고 볼펜으로 눌러 score, 아랫장과 골 방향 엇갈려 풀칠 (플랩 부분은 풀칠 금지).
2. Fin Ray 띠 4개: 리브 빨대를 R2–R8 표시에 테이프 힌지로 붙이고 → 삼각형으로 접어 탭 풀칠 → 밑판에 고정.
3. Fin Ray 2개씩 플랩 끝에 밑판 탭으로 수직 고정 (contact flank 가 안쪽).
4. Soft 드럼(큰-작은-큰)을 플랩 바깥면 힌지선 위에 세워 붙이고 삼각 보강, 손바닥 슬롯으로 아래 절반이 지나가는지 확인.
5. Hard 손가락 3장 적층(가운데 장 슬롯) → 드럼 끼워 풀칠 → 빨대 축 → 손바닥 모서리 굵은 빨대 부싱에 끼움.
6. 쐐기 받침 + 고무줄 패드, 손톱 플랩(테이프 힌지) + 스토퍼.
7. 실 감기: 드럼 안쪽 접선에서 위로. 좌·우 실 A → 균형막대 → 직렬 고무줄 → 손잡이. 실 B 도 같은 방식.
8. 복원 고무줄 걸고, 실 A/B 를 놓았을 때 완전 개방(플랩 수평, hard 40°)으로 돌아오는지 확인.
