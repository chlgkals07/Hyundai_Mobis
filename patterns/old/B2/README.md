## 부자재 (자르지 않음)

- 일반 빨대(Ø6) Fin Ray 리브: 손가락당 22.4 / 16.8 / 11.2 / 5.6 mm × 4개 손가락 (+ 테이프 힌지 양끝)
- 일반 빨대 핀: soft 70 mm × 4, hard 32 mm × 4
- 실 A: 캐리지 양끝 → 안쪽 → 손바닥 구멍, 실 B: 캐리지 → 슬롯 아래 고리 → 벽 면 따라 위로
- 복원 고무줄: 캐리지마다 1개(바깥쪽으로 당김)

## 조립 순서

1. 손바닥 2장 엇갈려 풀칠, 벽 위치(일점쇄선)와 실 구멍 표시.
2. 가이드 벽 4장·가운데 벽 1장의 탭을 접어 손바닥 아랫면에 풀칠. 직각 유지가 중요(삼각 보강 권장).
3. 슬롯에 빨대 핀을 넣어 캐리지가 걸림 없이 미끄러지는지 먼저 확인 (안 되면 슬롯 폭 +0.5 mm, 빨대에 연필심 문지르기).
4. Fin Ray 4개 조립 → 캐리지 판에 고정 → 핀으로 벽에 걸기.
5. Hard 갈래판 2장을 벽 양쪽에 두고 핀 2개로 연결 → 아래 브리지 → 패드·손톱.
6. 실·고무줄 연결 후 완전 개방 위치로 돌아오는지 확인.
