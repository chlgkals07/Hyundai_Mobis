## 부자재 (자르지 않음)

- 손톱 14 mm (3겹): 접히면 최대 11.6 mm 순응
- 빨대 슬리브 4개 × 10 mm: 손바닥 실 구멍(Ø6.5)에 끼워 풀칠, 실이 들어오는 쪽으로 살짝 기울여 꽂음. 끝은 둥글게 (가위 자국 → 실 걸림). 골판지 모서리 마찰 μ≈0.5 → 빨대 μ≈0.25
- 빨대 자르기 (빨대 2개면 충분): Fin Ray 리브 R2 약 20 · R4 약 15 · R6 약 9 · R8 약 4 mm(생략 가능) × 4개 손가락 — 도면 길이 22.4/16.8/11.2/5.6 에서 벽 두께만큼 짧게, 접은 삼각형에 대 보고 다듬기. 양끝 테이프 힌지 · 실 구멍 슬리브 10 mm × 4
- soft 실 (좌우 한 가닥, 교차): 오른쪽 플랩 매듭 → 손바닥 밑을 지나 왼쪽 구멍(x=−10) 위로 → 손잡이 → 오른쪽 구멍(x=+10) 아래로 → 손바닥 밑 → 왼쪽 플랩 매듭. 손바닥 밑에서 X 자 (구멍이 y 로 1.5 엇갈려 서로 안 닿음). 균형막대 불필요
- soft 복원 고무줄 2: 손바닥 윗장 고무줄 구멍 ↔ 플랩 바깥면. soft 열림 제한 실: 플랩 ↔ 손바닥, 열림 30° 에서 팽팽하게
- 영상용 힘: Fin Ray 손가락당 0.5 N → soft 실 6.5 N, hard pinch 1.5 N → hard 실 6.1 N (손가락 하나 기준). 손잡이는 두 가닥을 당기므로 손잡이 힘 ≈ 2배 (빨대 슬리브 포함: hard 13 N, soft 17.2 N, 팔 경로 마찰 제외). 복원 고무줄은 확실히 약하게
- hard 실 (앞·뒤 한 가닥, 교차): 앞 안쪽 링크 매듭 → 손바닥 밑을 지나 뒤쪽 구멍(y=−8) 위로 → 손잡이 → 앞쪽 구멍(y=+8) 아래로 → 뒤 안쪽 링크 매듭. 쥘 때 모멘트 팔 17.6–19.1 mm
- hard 복원 고무줄 2: 아랫변 바깥 끝 ↔ 손바닥 아랫면 바깥쪽 (약하게). hard 열림 제한 실: 아랫변 ↔ 손바닥, 열림 54° 에서 팽팽하게
- 테이프: 접는 상자 관절 4줄 × 2, Fin Ray 리브, 손톱 힌지. 빨대 핀·축 없음

## 조립 순서

1. 손바닥: 윗장(플랩 포함) + 아랫장(좌우 1.5 mm 좁게) 엇갈려 풀칠, 플랩 부분 풀칠 금지. 가운데 실 구멍 4개(빨대 슬리브), 플랩 매듭 구멍 2개(테이프 보강), 고무줄 구멍 2개를 함께 뚫음. 닫힘 스토퍼 블록 2개를 아랫면 표시에.
2. Fin Ray 4개: 띠를 병으로 굴려 골을 눌러 편 뒤 접어 삼각형, 리브 빨대 테이프 힌지 → 앞 탭 26 을 날개 안쪽 면 빗금 자리에 통째로 풀칠 (날개 하나에 2개).
3. 접는 상자 2개: 접는 선 4개를 깊게 눌러 양방향으로 길들이고 바깥 면 테이프 → 끝 탭을 윗변 안쪽 끝에 겹쳐 풀칠(납작한 상자) → 손으로 밀어 평행사변형으로 기우는지 확인 → 윗변을 손바닥 아랫면 빗금에 풀칠 (안쪽 링크가 가운데 쪽).
4. 손끝판(ㄱ자 2장 적층)을 아랫변 아래 안쪽 끝에 풀칠 + 삼각 보강, 손톱(3겹) 테이프 힌지 + 손톱 스토퍼 + 고무줄 2바퀴.
5. 실 (교차): soft 한 가닥(우 매듭 → 왼쪽 구멍 → 손잡이 → 오른쪽 구멍 → 좌 매듭), hard 한 가닥(앞 매듭 → 뒤쪽 구멍 → 손잡이 → 앞쪽 구멍 → 뒤 매듭). 손바닥 밑에서 X 자. 복원 고무줄과 열림 제한 실 → 전 범위 동작 확인.
