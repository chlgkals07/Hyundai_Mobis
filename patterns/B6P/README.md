## 부자재 (자르지 않음)

- 손톱 14 mm (3겹): 접히면 최대 11.6 mm 순응
- 일반 빨대(Ø6) Fin Ray 리브: 손가락당 22.4 / 16.8 / 11.2 / 5.6 mm (도면 길이, 실제는 벽 두께만큼 약 2 mm 짧게) × 4개 손가락, 양끝 테이프 힌지
- soft 실 (좌우 한 가닥 루프): 오른쪽 플랩 매듭 구멍 → 손바닥 구멍 x=+5 위로 → 손잡이 → x=−5 아래로 → 왼쪽 플랩 매듭. 균형막대 불필요 (한 가닥이 양쪽을 같이 당김)
- soft 복원 고무줄 2: 손바닥 윗장 고무줄 구멍 ↔ 플랩 바깥면. soft 열림 제한 실: 플랩 ↔ 손바닥, 열림 30° 에서 팽팽하게
- 영상용 힘: Fin Ray 손가락당 0.5 N → soft 실 9.5 N, hard pinch 1.5 N → hard 실 9.9 N. 복원 고무줄은 이보다 확실히 약하게
- hard 실 (앞·뒤 한 가닥 루프): 앞 안쪽 링크 매듭 → 손바닥 가운데 구멍 위로 → 손잡이 → 같은 구멍 아래로 → 뒤 안쪽 링크 매듭. 쥘 때 모멘트 팔 10.8–11.7 mm
- hard 복원 고무줄 2: 아랫변 바깥 끝 ↔ 손바닥 아랫면 바깥쪽 (약하게). hard 열림 제한 실: 아랫변 ↔ 손바닥, 열림 54° 에서 팽팽하게
- 테이프: 접는 상자 관절 4줄 × 2, Fin Ray 리브, 손톱 힌지. 빨대 핀·축 없음

## 조립 순서

1. 손바닥: 윗장(플랩 포함) + 아랫장(좌우 1.5 mm 좁게) 엇갈려 풀칠, 플랩 부분 풀칠 금지. 가운데 구멍 3개와 플랩 매듭 구멍 2개, 고무줄 구멍 2개를 함께 뚫음. 닫힘 스토퍼 블록 2개를 아랫면 표시에.
2. Fin Ray 4개: 겉종이 벗긴 띠를 접어 삼각형, 리브 빨대 테이프 힌지 → 앞 탭을 플랩 안쪽 면 표시에 풀칠 (플랩 하나에 2개).
3. 접는 상자 2개: 접는 선 4개를 깊게 눌러 양방향으로 길들이고 바깥 면 테이프 → 끝 탭을 윗변 안쪽 끝에 겹쳐 풀칠(납작한 상자) → 손으로 밀어 평행사변형으로 기우는지 확인 → 윗변을 손바닥 아랫면 빗금에 풀칠 (안쪽 링크가 가운데 쪽).
4. 손끝판(ㄱ자 2장 적층)을 아랫변 아래 안쪽 끝에 풀칠 + 삼각 보강, 손톱(3겹) 테이프 힌지 + 손톱 스토퍼 + 고무줄 2바퀴.
5. 실: soft 한 가닥(좌 매듭 → 구멍 → 손잡이 → 구멍 → 우 매듭), hard 한 가닥(앞 매듭 → 가운데 구멍 → 손잡이 → 같은 구멍 → 뒤 매듭). 복원 고무줄과 열림 제한 실 → 전 범위 동작 확인.
